# CodexOnModal_Grok — инструкция

## Что это

Сервер в облаке **Modal** (не на твоём ПК):
- Debian 12
- 4 CPU, 16 ГБ RAM
- диск Volume `debian512` → `/mnt/data`
- вход по **SSH через публичный tunnel** (с другого компа Modal CLI не нужен)

Код: https://github.com/NeuBeginner/CodexOnModal_Grok  
Рабочая папка на ANNI: `D:\Install\I\Dropbox\Coding\Grok`

## Как зайти с другого компьютера

1. Открой актуальные `HOST` и `PORT`:
   - файл `connection.txt` в этой папке, **или**
   - на ANNI: `modal run keepalive_modal.py::show`
2. Подключись:
   ```bash
   ssh -p PORT root@HOST
   ```
   Пример (меняется после recreate):
   ```bash
   ssh -p 44363 root@r444.modal.host
   ```
3. Пароль: файл `root_password.txt` (локально, **не в git**).

ПК ANNI для входа по SSH **не нужен** — сервер в Modal.

## Запуск / пересоздание сервера (когда ПК включён)

```bat
cd /d D:\Install\I\Dropbox\Coding\Grok
python server_ssh.py
```

Новые `HOST`/`PORT` запишутся в `connection.txt`.

Нужны: Python, `pip install -U modal`, один раз `modal setup`.

## Чтобы сервер жил ~7 дней при выключенном ПК

У Modal один Sandbox живёт **максимум 24 часа**.

Уже задеплоен облачный keepalive (крутится у Modal, ANNI можно выключать):
https://modal.com/apps/myn40479/main/deployed/codex-on-modal-keepalive

Он примерно каждые 20 часов пересоздаёт Sandbox.  
**После recreate меняются HOST и PORT** — смотри `connection.txt` или:

```bat
cd /d D:\Install\I\Dropbox\Coding\Grok
modal run keepalive_modal.py::show
```

Передеплой keepalive (если менял код):

```bat
cd /d D:\Install\I\Dropbox\Coding\Grok
modal deploy keepalive_modal.py
```

Секрет пароля в Modal: `ssh-root-password` (ключ `ROOT_PASSWORD`).

## Файлы в папке

| Файл | Назначение |
|------|------------|
| `server_ssh.py` | Создать Sandbox + SSH tunnel |
| `keepalive_modal.py` | Keepalive в облаке Modal (~7 дней) |
| `keepalive.py` | Локальный keepalive (нужен включённый ПК) |
| `connection.txt` | Текущие HOST/PORT (**не в git**) |
| `root_password.txt` | Пароль root (**не в git**) |
| `HOW_TO.txt` / `README.md` | Эта инструкция |

## Важно

- Данные клади в `/mnt/data` — они переживают recreate.
- Публичный SSH: кто знает host/port/пароль — зайдёт. Лучше сменить пароль (`passwd`) или ключи.
- Не коммить `root_password.txt` и `connection.txt`.
